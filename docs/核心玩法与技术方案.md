# 核心玩法、主题方向与 3D 技术方案

> 2026-11-09 草案。市场数据见 [市场调研-2026-11.md](市场调研-2026-11.md)。技术部分参考 Swarm Orbit（`D:\jump`）的 `docs/design/tech.md`、`docs/platform.md`、`docs/design/art.md`。

## 1. 从暴力摩托里拿什么

只拿玩法骨架，不拿名字、人物、美术、音乐、赛道。

### 1.1 核心循环（拆成 5 个可复用的机制）

| # | 机制 | 原作里的样子 | 我们要保留的本质 |
|---|---|---|---|
| A | **边跑边打** | 并排时出拳、踢、挥棍，把对手打下车 | 竞速中途可以"处理掉"对手，名次不只靠速度 |
| B | **抢武器** | 打掉对手手里的棍子就归自己 | 战斗中有临时掉落，打赢一次后下一次更强 |
| C | **摔车代价** | 撞车或被打下车后人飞出去，跑回车上 | 失误有明显、好笑、但不致命的代价（丢几秒和名次） |
| D | **路上的麻烦** | 车流、对向车、动物、警察追捕 | 赛道本身在制造风险，躲障碍和打架抢同一个注意力 |
| E | **奖金换装备** | 名次给钱，买更快的车；车损太重或被抓要付钱 | 每局之间有成长，局内表现决定成长速度 |

另外两个原作特征，网页版**不照搬**：

- 14 人长赛道（一局 3–5 分钟）：太长。改成 60–120 秒一段，6–8 个对手。
- 键盘组合键战斗：手机上做不了。改成单指操作，见 1.3。

### 1.2 一局的节奏（目标 120–180 秒）

```
起跑 5s → 车流段 25s → 第一次并排冲突 → 捡武器 → 障碍段 → 警察/追兵出现 → 冲线 → 结算
                         ↑ 每 8–12 秒一次"可打的人在旁边"
```

- 平均游玩时长目标仍是 10 分钟（Playgama 指标）。靠"再来一局"堆起来：一局 120–180 秒（2026-11-09 从 90 秒改），结算 10 秒，升级 15 秒，大约 3–4 局。
- Swarm Orbit 的教训：真实中位数只有约 90 秒，大部分人在第 3 波前就走了。所以**第一局的前 20 秒必须已经打到人、摔过一次车**，不能先教 30 秒操作。

### 1.3 操作（单指，竖横屏通用）

| 输入 | 动作 |
|---|---|
| 自动油门 | 不需要按加速（超休闲门户的默认做法） |
| 左右拖动 / 左右键 | 换道或转向 |
| 点击（对手在旁边时） | 朝有人的那一侧出手；两侧都有人就打近的那个 |
| 向下滑 / ↓ | 刹车，躲警察或让对手先过去 |
| 长按（可选，后期解锁） | 蓄力重击 |

- 攻击判定做"宽容"：对手进入侧面范围时高亮，点任意处就打。不让玩家精确瞄准。
- **出手有代价**（2026-11-09）：每次出手自己掉 10% 速度（`ATTACK.selfSlow` 0.9），打中对方掉 14%（`ATTACK.slow` 0.86）。打中净赚一点，打空纯亏，所以不能见人就打。
- 不用 Esc 暂停，暂停键是 P，暂停按钮从第一帧就画出来（Swarm Orbit 和 Tidehook 的教训）。

### 1.4 成长线

- **车/坐骑**：速度、操控、耐久三条属性，用奖金升级。
- **武器槽**：开局可选一件带进场的武器（棍、链、平底锅之类，视主题而定），局内捡到的只用到本局结束。
- **对手档案**：6–8 个固定对手，有名字和性格。被同一个人打下车 3 次会弹出"仇人"标记，打回去给额外奖金。原作玩家最记得的就是这个，成本低。
- **激励广告位**：结算奖金 ×2；摔车后立刻回到车上（跳过跑回去）。插屏只在两局之间。

## 2. 主题和表现形式

2. **布娃娃**

3. **警察追逐**
   - Blacktop Police Chase：Poki 汽车类增长最快，美国 450 万

**最重要的一条：这个玩法已经有人做了。** **Smash Speed!**（JoyBits，2026-06-05 上线）：

- Playables 上 5 个月 1100 万播放，已经上了 CrazyGames。
- 玩法是骑摩托穿车流、撞翻对手（对手头上的数字比你小就能撞翻）、打 Boss 卡车、升级车。
- 这几乎就是暴力摩托的骨架。

这说明需求被验证了，但只做"摩托 + 撞人 + 升级"会和它正面撞。差异化要靠：

- 主题
- **近身出手**（不是比数字撞）
- 摔车布娃娃的笑点
- 仇人系统

**上升中**（近 90 天上线）：

- **身边的人搞笑**：Annoying Uncle Punch Game 47 天 2400 万（每天约 51 万），Teacher Life 950 万
- **怪载具**：Shift Shapes Car 2 个月 1800 万（每天约 35 万）
- **obby**：10–11 月新上 14 款，最好的只有 280 万
- **brainrot / "67"**：上新量大，但没有一款进前 50

**平台方面：**

- Poki 汽车类占美国播放 10%，前 5 名拿走近 40%；平均时长最长的是 Smash Karts（573 秒，竞速 + 道具对战）。
- CrazyGames 首页有"Meme & bloxy"合集。

### 2.2 美术和方向

- Playables 前 50 约 80% 是**低多边形风格化 3D**（超休闲手游移植），角色多为无脸假人或卡通人物。前 50 里没见到像素风和体素风。
- 竞速类分两派：低多边形（Race Master、Turbo Stars）和半写实车（Racing Limits、Traffic Racer 3D）。
- **方向是硬性要求**：
  - YouTube 禁止锁方向，所有比例都要能玩。
  - Playgama 要求竖屏 + 适配好的横屏，不能有黑边。
  - CrazyGames 不收横屏带黑边的手游移植。
  - 所以第 3.6 节的车后追尾镜头、两种方向各调一套，是必须做的，不是加分项。
- **我们的优势**：Swarm Orbit 已经验证了"代码生成模型 + 顶点色"的路线（不用 PBR、不像 AI 图）。Playgama 拒收全 AI 生成的游戏，并说 AI 画面的游戏数据差一倍以上；YouTube 也要求不能看起来像 AI 做的。

### 2.4 推荐：1 为主题，4 的怪载具做成长线，3 做局内压力

**主题定为碰撞测试假人。** 理由：

1. **和核心玩法天然一致**："被打下车 → 飞出去"本来就是碰撞测试的主题，摔车从惩罚变成笑点（机制 C）。
2. **踩在两个大类的交集上**：无脸假人是 Playables 前 50 的主流角色，撞车/布娃娃是竞速类最大的子类。
3. **合规最干净**：没有血、没有真人、没有 IP；13+ 全年龄，YouTube 和 Poki 都过。
4. **美术最便宜**：假人就是几段圆柱和球，代码就能拼出来，正好走 Swarm Orbit 的代码建模 + 顶点色路线。布娃娃也就是 5–7 个节点（第 3.3 节）。
5. **和 Smash Speed 拉开**：
   - 它是写实摩托 + 比数字撞人，我们是假人 + 近身扇 + 飞出去的布娃娃。
   - 缩略图一眼能分开：假人在半空中，对手的拳头还在画面里。

**从 4 拿来"怪载具"做成长线**（Shift Shapes Car、Scooter Xtreme 证明载具新奇感能卖）：

- 起步：试验场滑板车
- 解锁：购物车 → 办公椅 → 老年代步车 → 马桶火箭 → ……
- 每种载具手感不同（速度/操控/耐久三条属性的不同取舍），也是皮肤付费点。

**从 3 拿来"警察"做局内压力（机制 D）：**

- 试验场的安保车会追上来挡在你前面，或者并排把你往护栏挤、让你掉速，但从不撞你（见 3.3.3）。
- 后期可以加一个"你当安保抓逃跑假人"的反向模式，但不做主线。

**5（骑士）留作节日活动皮肤**：假人穿盔甲骑木马，成本只是换装。

### 2.5 表现形式

| 项 | 方案 |
|---|---|
| 场景 | 一条贯穿多个"测试场"的公路：试验跑道 → 城市街道 → 高速 → 工地 → 机场跑道。每段换配色和路边景物，不换玩法 |
| 色调 | 碰撞测试经典的**黄黑**做主角识别色（假人 + 测试贴纸），环境用饱和的蓝绿天空和灰路面，高对比 |
| 镜头 | 车后追尾，竖屏偏高偏俯视，横屏偏低偏贴地；出手时轻微拉近，摔车时短暂慢动作 + 跟拍飞出去的假人 |
| 声音 | 打击用"咚"的空心塑料声（假人是空心的），不用肉体声；摔车时配一声测试员的"哦——" |
| 缩略图 | 1:1 不带文字；假人在半空中翻转，旁边对手的拳头/平底锅还停在出手位置；黄黑主色，背景简单（照 Poki 指南） |
| 名字 | 不带 Road Rash 或任何原作字样，也不碰 Smash Speed。候选：Dummy Brawl、Crash Lane Dummies、Slap Lane。**还没查重名和商标**，定之前要查 |

## 3. 3D 技术方案（照搬 Swarm Orbit 的架构）

### 3.1 技术栈

| 项 | 选择 | 理由 |
|---|---|---|
| 渲染 | Three.js（跟 Swarm Orbit 同版本，r186） | 已有完整的加载、预热、分档经验 |
| 语言/构建 | TypeScript strict + Vite，`base: './'` | 同上 |
| 模拟 | 30 Hz 固定步长，和渲染分开；无头 bot 可跑 | 用 bot 调每局时长、名次分布、经济曲线 |
| 平台 | `Platform` 接口：playgama / stub / offline，后面加 youtube、crazygames | Bridge 失败或 10 s 没初始化完就走 offline |
| 资源 | glTF + Draco，单独文件不内联 | Swarm Orbit 把 GLB 拆出来后主包 gzip 512 → 253 KB |
| 包体 | 首包 gzip ≤ 5 MB，`npm run package` 超了直接失败 | Poki 首包 8 MB、YouTube 30 MB，5 MB 三边都过 |

### 3.2 加载

照抄 Swarm Orbit 的 `boot.ts` 流程：

1. `index.html` 内联启动画面（深色底 + 进度条），第一个字节就有东西看。
2. SDK 初始化和游戏 chunk + GLB 的流式下载**并行**，按真实字节显示 8% → 90%，大小在构建时由 `bootSizes` 插件写进去。
3. `import('./main')` 不等 `initialize()`。第一帧画完后淡出 0.35 s，再发 `gameReady`。
4. Bridge 的 script 标签放在 `</body>` 前，不放 `<head>` 第一位（会白屏）。
5. iframe 为 0×0 时不初始化，等 resize。
6. WebGL context lost 时显示 ↻ 按钮。

### 3.3 竞速游戏特有的渲染问题

Swarm Orbit 是固定场地，这里是一直往前跑的路，多出几件事：

| 问题 | 做法 |
|---|---|
| 无限长的路 | 路面按段（chunk）生成，样条曲线 + 起伏；身后的段回收进对象池，不新建 |
| 视距 | 雾 + 远处低模，视距 150–250 m；雾色就是天空色，不用天空盒贴图 |
| 车流和对手 | 每种车一个 `InstancedMesh`（Swarm Orbit 的虫子就是这么做的）；轮子转动、受击闪白放进 instance 属性和顶点着色器 |
| 路边景物 | 按种类合并成 InstancedMesh，静态的用 `flatten.ts` 合批（Swarm Orbit 火车 53 → 22 次绘制） |
| 摔车飞人 | **只在视图层**做简化布娃娃：12 个点的 Verlet（头、双肩、骨盆、肘、手、膝、脚），不上物理引擎。模拟层只记"摔了、落点、几秒后归位"，保证 bot 可跑、可复现 |
| 速度感 | FOV 随速度变大、路边速度线、镜头轻微抖动；这些都便宜，比加模型细节划算 |
| 打击感 | 命中停顿 2–3 帧、受击闪白、数字飘字用字形图集 1 次绘制（Swarm Orbit 的做法） |

### 3.3.1 美术管线：代码建模 + 顶点色 + 卡通着色 + 描边（2026-11-09 第一版）

全部模型在代码里用圆角盒、胶囊、球、圆柱拼出来，不用贴图、不用模型文件、不用 AI 生成。代码在 `src/view/toon.ts`。

- **`Kit`**：把一个物体的零件（几何体 + 颜色 + 位置）合并成**一个几何体**，颜色写进顶点。一辆车、一条胳膊各是 1 次绘制。
- **着色**：`MeshToonMaterial`，3 档明暗的渐变图（`NearestFilter`），全游戏共用 1 个材质。
- **描边**：反向外壳（inverted hull），**烘进同一个几何体**：每个零件再复制一份，沿平滑后的法线外推 2.4–4.5 cm，翻转绕序，涂深色。不加后处理，不多一次绘制，代价是三角面翻倍。贴纸、灯、小零件不描边。
- **车的颜色**：每种车型一个 `InstancedMesh`。车身零件带 `paint=1` 顶点属性，着色器里只让实例颜色染车身，玻璃、轮胎、描边不变色。
- **车型由 `car.id` 哈希决定**，只在视图层。模拟层不知道车型，碰撞框仍是 1.9 × 4.4 m，所以五种车都要装进这个框里。金哈希不变。
- **假人**：每个骑手 5 次绘制（滑板车、腿 + 骨盆、躯干 + 头、左右胳膊），各自一个材质，`emissive` 做受击闪白。布娃娃用同一个材质，也带描边和头部贴纸。
- **测试贴纸**做成几何体：4 个黑黄相间的四分之一圆 + 黑边，不用透明贴图。

| 物体 | 三角面（含描边） |
|---|---|
| 骑手（人 + 车 + 武器外） | 约 4.9k |
| 车（5 种） | 2.3k–3.1k |
| 布娃娃 | 约 0.6k |
| 巡逻车 | 约 1.6k |

**实测**（1280×720，10 个骑手，比赛中）：29–51 次绘制，128–150k 三角面。改之前是 34 次、86k。手机预算按 100 次绘制、200–300k 三角面算，还有余量。

- **大头在赛道本身**：整条地面、护栏、树是全程的大网格，不做视锥剔除（地面约 26k、树约 15k、护栏约 14k）。要省就先按段切开。
- **`?stats`**：左下角显示帧率、最慢一帧、绘制次数、三角面、几何体和着色器程序数。在手机上调美术时用。

**还没做的**：路边景物（树、路牌、门架）还是旧的 Lambert 材质；还没在真手机上测帧率。

### 3.3.2 打击感、布娃娃和安保车避让（2026-11-09）

**出手动作**（`src/view/rider.ts`）：0.42 秒分三段。前 0.2 秒蓄力（胳膊往后拉、上身扭过去），0.2–0.36 秒甩出去（上身反扭、往前探），然后缓回原位。模拟层在出手后第 4 帧（约 0.13 秒）判定命中，正好落在甩出去那一段。甩的时候身后带一道白色扇形拖影，左右出手用 `scale.x = side` 镜像。

**被打中**：
- 身体往挨打的方向倒（`lean.rotation.z` 上的弹簧，k=170、阻尼 11），KO 倒得更多。
- 上身压扁再弹回（squash & stretch），受击闪白。
- 命中点冒一个朝镜头的漫画爆炸星（`fx.pow`）：黑边 + 黄色（KO 是橙红）+ 白芯，先放大到 1.3 倍再缩回、旋转、0.3 秒淡出。6 个循环复用，不做深度测试。

**布娃娃**（`src/view/ragdoll.ts`）：
- 12 个点，棍子分两种：一种保持长度，一种只限最短距离（当关节限位，防止胳膊腿折进身体）。
- 躯干朝向由双肩和骨盆算出，头跟躯干走；四肢各一段几何体，从肩/髋接出去。
- 甩出去时给整个身体一个角速度（`ω × r`），所以会翻跟头而不是平移。力度看怎么摔的：被车撞 1.45，被打下车 1。
- 头、肩、骨盆砸地速度超过 4 m/s 时冒一团灰（`fx.puff`），0.18 秒内最多一次。

**安保车避让**（模拟层，`World.patrolTraffic`）：
- 原来安保车只管追人，直接从车流里穿过去。现在对每个横向位置算"多久会撞上最近一辆车"；要去的位置不到 1.4 秒就会撞，就换一个分数最高的车道（`min(净空时间, 4) - 偏离距离 × 0.1`，逆行车道扣分）。
- 旁边有车时不横移进去；同向前车太近就限速跟车。车流看到前方 10 m 内同道有安保车也会减速。
- 测试 `src/sim/patrol.test.ts`：8 局 bot 比赛，安保车和车重叠的帧数必须为 0（改之前是 1230 帧）。
- 这是模拟层改动，`SIM_VERSION` 升到 3，金哈希更新。

### 3.3.3 警车只挡不撞，暴徒和对手一样打（2026-11-09，SIM_VERSION 5）

试玩反馈：警车和暴徒对玩家的伤害太明显，让人反感。第一版（SIM_VERSION 4）只是把数值调软（被抓不下车、罚款减半、暴徒少出手），方向不对。改成：

**警车：挡路或挤你，但从不撞你**（`World.updatePatrol` / `patrolContacts`）
- 从后面上来时走相邻车道，不往玩家背上顶。离玩家 13 m 时响警笛，轮流用两招：
  - **挡路**（block）：从旁边超到你前面 6 m，切进你的线，按你极速的 80% 开。你要变道绕过去，或者跟在后面吃亏。
  - **挤压**（squeeze）：和你并排，往你这边压。贴着它会摩擦掉速（每帧保留 99.3%），被压到护栏上再额外掉速（每帧 99%），实测 3 秒内从 30 m/s 掉到 20 m/s。刹车或者变道就能脱身。
- 每招最多 4 秒（SIM_VERSION 6 起），然后让开你的线、刹车退出比赛。见 3.3.4。
- 警车是实心的：骑手在它旁边会被推开（同手动挤压一样冒火花），在它后面会被挡住，在它前面它会刹车。接触面用上一帧的相对位置判断，不会中途翻转。
- 没有罚款、没有"被抓"、不会因为警车摔车（`CrashCause` 里去掉了 `'patrol'`）。
- 横移时按"这一帧走完后的位置"检查车流，不会贴着慢车尾巴切进去；后面有车追上来时自己加速，不让车顶进车里。

**暴徒：就是带家伙的对手**（`thugThink`）
- 出手概率和普通对手一样（`激进度 0.9 × AI.swingAtPlayer`），血量一样（3）。
- 一定带武器：前半程平底锅，过了 50% 赛程领头的那个拿棒球棍。
- 你可以反击；打下车后它的武器掉在路上，可以捡。
- 追杀者的出手倍率、领跑威胁间隔恢复到原来（2.5 倍；11 s → 5 s）。保留"玩家摔车后 10 s 不来新威胁"。

**实测**（24 局，bot 速度和操控各升 3 级，代表能领跑的玩家，不主动找架打）：

| 每局 | 数值 |
|---|---|
| 完赛时间：有警车 / 没有警车 | 152 s / 152 s（警车只是麻烦，不吃时间——bot 不会躲，真人会更灵活） |
| 被暴徒打中 / 打下车 | 1.2 / 0.8 |
| 你打中暴徒 / 打下暴徒 | 3.4 / 1.0 |
| 平均名次 | 2.1 |

测试 `src/sim/patrol.test.ts`：警车和车重叠帧数为 0；任何骑手每帧结束时都不在警车里面；挤压时玩家平均每帧净掉速超过 0.05 m/s。

### 3.3.4 每辆警车只来一次（2026-11-09，SIM_VERSION 6）

试玩反馈：一辆警车老跟着我。可以多几辆，但不能一辆一直跟。

现在同一时间路上最多一辆警车，但每辆只出一招，出完就走（`World.updatePatrol` / `sendPatrol`，状态 `chase | lurk | block | squeeze | leave`）：
- **出场**：赛程 25% 之后开始；终点前 300 m 不再来新的。轮流三种来法：
  - 第 1、4、7 辆：从后面 55 m（镜头外）追上来，挤你。
  - 第 2、5 辆：在前方 150 m 的同向侧车道（车道 1 或 3）慢慢开，速度是你的 45%；出场时挑一个附近没车的位置，挑不到就过 1 秒再试。你追到它后面 40 m 时响警笛，横切到你前面挡路。
  - 第 3、6 辆：从后面追上来，挡路。
- **出招**：挡路或挤压各最多 4 秒（挡路的计时从它真正挡在你前面才开始）。
- **离开**（leave）：先让开你的线，然后比你慢 15 m/s，落到你身后 30 m（镜头外）或者超出你 200 m 时消失。你冲线时它也马上离开。
- **下一辆**：上一辆消失后过 12 s 来下一辆（赛程越往后越短，终点附近 7 s）。
- 你摔车时，正在追的车停在你身后 30 m 等你骑起来；正在出招的车直接离开。追了 20 s 还没追上的车也离开。

**实测**（60 局，bot 速度和操控各升 3 级，不主动找架打）：

| 每局 | 数值 |
|---|---|
| 来的警车 / 真正出招的 | 4.5 / 4.4 |
| 单辆警车在路上最长 | 33 s（大部分时间在镜头外追） |
| 完赛时间：有警车 / 没有警车 | 157 s / 156 s |
| 平均名次：有警车 / 没有警车 | 2.2 / 2.4（差别在噪声范围内） |

测试 `src/sim/patrol.test.ts` 新增一条：同一辆车不会响第二次警笛；每局至少 3 辆；单辆在路上不超过 40 s。

### 3.3.5 警车随机化（2026-11-09，SIM_VERSION 7）

试玩反馈：警车能随机一些吗——数量、时间、出现方式都随机。

3.3.4 的规则不变（同一时间最多一辆，每辆只出一招就走），但固定轮换改成按局、按车掷骰子。警车用自己的随机流 `patrolRng = seed*17+11`，不影响车流和对手 AI。区间都写在 `C.PATROL` 里，格式是 `[最小, 最大]`。

- **数量**：每局 2–6 辆（`count`）。
- **第一辆什么时候来**：赛程 12%–40%（`startAt`）。车多的局来得早，再加一点抖动。
- **间隔**：基础间隔还是 12 s 到 7 s，再乘两个系数：
  - 车多的局乘 0.35，车少的局乘 1.7（`busyGap`）。
  - 每次再乘 0.3–1.8 的随机数（`gapJitter`）。
  - 另有 20% 的概率下一辆 1.5–4 s 后就来，紧跟着上一辆（`pairChance` / `pairGap`）。
- **来法**：每辆从四种方案里随机挑一种，不和上一辆重复。
  - 后面追上来挡路
  - 后面追上来挤压
  - 前方等着，横切挡路
  - 前方等着，你到它旁边时贴过来挤压
- **每辆自己的参数**：
  - 从后面出场的距离 45–70 m
  - 在前方等待的距离 120–190 m
  - 等待时的车速是你极速的 35%–55%
  - 横切时机：你追到它身后 25–45 m 时
  - 挡路时在你前方 5–8 m
  - 出招时长 2.5–5 s
- **离开**：
  - 在你前面时加速开走，超出你 45 m 就消失。
  - 在你后面时减速，落后 30 m 消失。
  - 在你身边被车流卡住超过 5 s（你也被它挡着），就直接下道消失。
- **车流修正**：警车在车流里留的前后余量加到 0.8 m，抵消"车流先动、警车后动"那一帧的位移。另外，后面来车逼它加速时，不会让它顶到前面那辆车。

**实测**（60 局，同上的 bot）：

| 每局 | 数值 |
|---|---|
| 警车数 | 2 辆 14 局，3 辆 11 局，4 辆 15 局，5 辆 9 局，6 辆 11 局 |
| 第一辆出现 | 第 19–73 s |
| 四种来法 | 各约 1/4 |
| 单辆警车在路上最长 | 33 s |
| 完赛时间：有警车 / 没有警车 | 160 s / 156 s |
| 平均名次：有警车 / 没有警车 | 2.9 / 2.4 |

### 3.3.6 摔车后车滑出去，人跑回车上（2026-11-09，SIM_VERSION 8）

试玩讨论：摔倒后加一个跑向自己车的过程。这也让广告位"摔车后立刻回到车上（跳过跑回去）"有了实际内容。

**模拟层**（数值在 `C.DOWN`）：

- 摔车时人和车分开。
  - 人以 20 m/s² 减速，躺够 30 tick（被打下车）或 40 tick（撞车）。
  - 车以 11 m/s² 减速，所以车总比人滑得远，越快越远。车只吃 60% 的横向推力。
- 人停稳后起身，跑向车：
  - 0.25 s 内提速到 8 m/s，横向按 0.7 倍速度挪。
  - 离车 1 m 内就回到车上，位置换成车的位置。
  - 最多跑 4 s，超时也放回车上。
- 暴徒摔车还是直接退场，不跑。
- `Rider` 新增 `bikeX/bikeZ`（和上一帧的 `bikePX/bikePZ`）、`bikeV/bikeVx`、`runT`。`runT > 0` 表示正在跑。
- 测试 `src/sim/down.test.ts`（种子 1–6）检查：
  - 八成以上的摔车有跑回去的阶段。
  - 躺着时车不会在人身后。
  - 回到车上时就在车的位置。
  - 倒地最长不超过 `maxRun + 1` 秒。

**视图层**：

- 倒地时 `RiderView` 只画躺倒的滑板车，放在车的插值位置。车向摔出去那一侧转约 50°。
- 布娃娃的落点和模拟层的人不一致，常差几米。
  - 所以跑步从布娃娃实际停下的位置开始，朝车跑。
  - 进度跟模拟层同步：用模拟层的人离车的剩余距离折算。这样两边在同一 tick 到车上，回车时不会瞬移。
- 起身用 0.35 s 从躺姿混到跑步姿态。跑步是程序动画：腿和手臂交替摆、身体上下颠、上身前倾，面朝车。
- 跑的时候物理停掉，`hide()` 后下次摔车重新开始。

**实测**（40 局，同上的 bot）：

| | 改之前 | 改之后 |
|---|---|---|
| 每次倒地时间 | 2.0–2.4 s，平均 2.22 s | 1.0–3.8 s，平均 2.27 s |
| 其中跑回去 | — | 平均 1.07 s，最长 2.4 s |
| 车和人拉开的距离 | — | 平均 5.0 m，最远 9.5 m |

倒地总时长基本不变，但快速撞车的代价变大，轻碰变小。完赛时间 161 s → 155 s，平均名次 3.0 → 2.35。倒地时长几乎没变，这个差距多半是因为规则一改，同一个种子跑出来就是另一局；40 局的噪声不小，不要当成变容易了的结论。

**广告位接口（还没做）**："立刻回到车上"要做成一个输入：玩家点了广告且看完后，下一个 tick 在模拟层直接调 `recover()`。这会改变一局的结果，所以必须进回放：`InputRow` 要加一列（或加一种事件行），同时升 `SIM_VERSION`。等接激励广告时再做，现在不预留。

### 3.3.7 警车逼停：往路肩挤你，在前面拦你（2026-11-09，SIM_VERSION 9）

试玩反馈：警车追上来以后没有往旁边挤我。警察是要我停车的，所以应该把我往边上挤；在前面拦我也一样。我要自己看车流想办法躲过去。

原因：
- 旧的挤压在追上来时就往里压，结果顶在玩家车尾，被挡住了，根本没并排。
- 4 秒计时从响警笛就开始算，真正贴上的时间很短。

现在每辆警车的目的都是逼你靠边停车（`World.updatePatrol`，数值在 `C.PATROL`）。

**挤压（squeeze）：并排后往路肩推**
- 从后面来的警车一律挤压（方案只剩 `behind squeeze / ahead block / ahead squeeze` 三种）。
- 接近时走你左边隔一条车道，不往车尾上顶。你在逆向车道（x < -3.5）时才走右边。
- 和你齐头（前后差不到半个车长）后，才开始往里压。
  - 压的方向是远离它自己的那一侧（`push`），通常是右边的路肩。
  - 横移速度 6 m/s（`pushSteer`）。
  - 贴着你时摩擦掉速，每帧保留 99%（`rub`，原来是 99.3%）。
- **不把你推进车里**（`carOnShoulder`）：被推的那一侧 0.3–5 m 内有车，就退开 1 m，给你留出空隙。车要么在你旁边，要么 1.4 s 内会追上（`carWarn`）。
  - 所以脱身的办法是车流：贴着路肩那侧的车走，它就不敢压。从车缝里钻过去，它太宽，跟不过来。
- 计时（`hold`）只算真正贴上的帧数。出招时间到了就离开；另外有兜底：出招时间再过 6 s（`pressMax`）还贴不上，也会走。

**挡路（block）：在前面拦你，越开越慢**
- 切到你前面后跟着你的线横移，速度 8.5 m/s（`blockSteer`）。操控升满的骑手能甩开它。
- 车速从你极速的 80% 降到 55%（`blockPace`），在出招时间内逐渐降下来。
- 计时只算它真的在你前面 12 m 以内的帧。被你超过 2 m 就放弃。

**实测**（40 局，bot 速度和操控各升 3 级。bot 不会主动利用车流脱身）：

| 每局 | 有警车 | 没有警车 |
|---|---|---|
| 完赛时间 | 157.7 s | 152.7 s |
| 平均名次 | 3.08 | 2.15 |
| 摔车次数 | 8.5 | 8.1 |

- 挤压时平均贴上约 13 次。推向右侧路肩 22 次，推向左侧 6 次。车速最多从 30 m/s 被挤到 14 m/s。
- 有一部分撞车发生在挤压期间，逐帧查过：
  - 都是 bot 自己转向撞上的车。当时警车要么还没贴上来，要么已经因为路肩有车退开了。
  - 没有一次是警车把人推进车里。

测试：`src/sim/patrol.test.ts` 不变，仍然通过：
- 挤压时玩家平均每帧净掉速超过 0.05 m/s。
- 警车和车不重叠。

`src/sim/down.test.ts` 放宽了一处：回到车上那一帧如果正好被挤，位置可能差 0.5 m。

### 3.3.8 AI 像人在开车：反应延迟、横向惯性、意图（2026-11-09，SIM_VERSION 10）

试玩反馈：AI 太简单。
- 警车挤我时我已经停车了，它还盯着我。
- 警车拦我时和我完全同步变道。对手也一样，完全复制我的变道方向。

原因：所有 AI 每帧直接读玩家当前的位置，横向又是匀速瞬时转向，所以玩家一动它们同一帧就跟着动。

**共用的一层（`World.seen`、`World.move`，数值在 `C.AI`）**
- **反应延迟**：每个骑手和警车都记着别人最近 24 帧的位置（`hx/hz/hv` 环形缓冲，`remember()` 每帧末尾写入）。
  - AI 看到的是 `react` 帧之前的样子，再按速度和一半的横向速度往前推一点（`predict` = 0.5）。
  - 对手的 `react` 按警觉度在 6–15 帧之间，每局再随机加 0–2 帧。警车 8–14 帧。
  - 所以急刹、急转要过一个反应时间才被看到；假动作会把它们往错的方向带。
- **横向惯性**：AI 不再瞬间对准目标线，而是要把横向速度加起来、再减下去（对手 13–22 m/s²，按警觉度；警车 11 m/s²）。
- **意图要坚持**：对手每 0.8–1.8 s 才重新想一次要干什么；绕车时选的线保持 0.7 s（`escHold`）。

**警车（`World.updatePatrol`）**
- **停车就放行**：挤压或拦截时，它看到你的车速低于 9 m/s 持续 0.4 s，就转入 `halt`。
  - 开到你前面隔一条车道停住，1 s 后弹出 `WARNING! MOVE ALONG` 并离开（事件 `patrolLetGo`）。
  - 你中途又加速走了（超过 14 m/s），它就回到原来的挤压或拦截。
- **挤压**：急刹会让它冲过头（看到的位置是旧的）。冲过头后，拦截时间还没用完就转成在前面拦你，否则离开。
  - 车身贴着你时它能"感觉"到你，反应只延迟 3 帧（`feel`），所以贴住以后不会一刹就甩掉。
- **有真实的极速**：每辆车在 33–38 m/s 之间随机。被甩开 80 m 就放弃（`outrun`）。速度升满的玩家能甩掉慢的那几辆。
- **按车道拦**：拦截时它守的是一条车道，不是你的每一次抖动。
  - 你越过车道线 0.3 m 以上（`laneCommit`）它才换道，换完至少守 12 帧（`laneHold`）。
  - 换道只按它真看到的位置判断，不做预测，所以一定比你晚一个反应时间。
  - 在车道内最多往你那侧偏 0.6 m（`laneShade`）。
  - 结果：真变道它晚半拍才跟上；假动作（晃出去马上回来）会把它骗到旁边车道停一会儿。
- 加了惯性以后它躲车变慢了，所以：
  - 躲车时打方向更猛（横向加速度 ×1.8），提前 2 s 看车（`dodgeT`，原来 1.4 s）。
  - 已经和车并排时，往远离那辆车的方向移动总是允许的。
  - 从后面刷出来时不在逆向车道。离开时如果要走到逆向车道一侧，就改走另一侧。
  - 刷新车流时不会把车刷在警车身上。

**对手（`rivalThink`，数值在 `C.AI`）**
- 三种意图：`race`（按车道跑、绕慢车、偶尔换道）、`harass`（盯上某人）、`back`（只剩 1 点血又挨了打，退开 2 s）。
- **盯人时选定一侧就不换**（`foeSide`），离你 1.2–1.65 m 再加武器距离的 0.6 倍。在这个距离上随机晃动 ±0.35 m（`wander`），不会死贴，也不会镜像你的变道。
- **性格**：盯玩家的概率是每次重新思考 1.1 × 攻击性（14 m 内），盯别的对手是 0.12 × 攻击性（10 m 内）。盯 4–7 s（再乘 0.6 + 攻击性），之后歇 2–4 s。
- **记仇**：上一个打中它的人（`hitBy`）被盯上的概率翻倍。
- **挥棒时机**：对方和它齐头、且刚挥过棒（有空档）时更愿意出手（×1.8）。还没对齐时减半，退开时只有 0.3。
- 追领先者（hunt）时不受极速上限限制，能追得上。橡皮筋略微加强：落后时最多 +20%（原来 +16%）。

**暴徒（`thugThink`、`startAmbush`）**
- 两个一组时分工：
  - 50% 是**钳形**，左右各一个。
  - 否则一个**主攻**，另一个**拦路**：在你前面 3.5 m、按你车道（同样有换道门槛和最短守道时间）、以你 92% 的速度骑，让你骑进战斗里。和你齐头了，或者出招时间过半，就转为主攻。
- 侧向距离按武器长短定。快被打下车时也会先退开，再回来打。

### 3.3.9 打进车流、预警和反击、抢武器、通缉等级、罚款（2026-11-09，SIM_VERSION 11）

**一局时长**：目标从 90 秒改为 **120–180 秒**（2026-11-09 试玩后决定，现在的节奏是对的）。实测竞速 bot 146 s，打架 bot 174 s，都在范围内。

**第一次交手**：设计要求前 20 秒内打到人。实测（40 局，`_first.ts`，已删）第一次交手的中位数是起跑后 3.5 s，已经满足，不用改。

**打进车流 / 撞墙（`SHOVE`、`SHOVE_BONUS`）**
- 被打中的人会被推向侧面：推力 = 基础 5.5 + 武器推力（平底锅 +1，球棒 +2）。
- 硬直 `stagT` 期间不能转向（玩家 3 帧，AI 6 帧）。横向速度每帧保留 0.88（平时 0.82），所以会被一路带过去。
- 被打后 24 帧内（`shoveT`）：
  - 撞上车：照常摔车，算到打人的人头上。
  - 撞上路边护栏，且横向速度朝外超过 1 m/s：摔车，原因 `wall`。
- 玩家这样把人打下去：+$100（`SHOVE_BONUS`）、慢镜头、`INTO TRAFFIC!` / `INTO THE WALL!`。如果是仇人，同时算报仇。
- 球棒或平底锅能把外侧车道的人打上护栏；空手只能把已经贴着护栏的人打上去。路中间挨一下只会偏离路线。

**预警和闪避反击（`ATTACK.windupAI`、`dodgeX/dodgeZ`、`open`、`counterDmg`）**
- AI 出手要蓄力 10 帧（0.33 s），玩家仍是 4 帧。
- 蓄力期间有三种提示：
  - 动作：举高、往后拉、发抖。
  - 名字牌：变红闪烁。
  - 屏幕边缘：来袭方向出现红色 ⚠，并有提示音。
- 出手时按目标蓄力开始时的位置和速度外推。目标实际偏离外推位置横向超过 1 m 或纵向超过 0.8 m，就算闪开：`DODGED!`，不会误伤旁边的人。
- 打空的 AI 露出破绽 24 帧：减速 6%，不能出手，名字牌变黄 💥。
- 这时玩家打中它就是反击（`COUNTER!`）：伤害 +1，必定打掉它的武器。

**抢武器（`STEAL`）**
- 打中拿武器的人时有概率打掉：玩家打 35%，AI 打 15%，反击必定打掉。
- 打人的一方空手、且不是暴徒：直接抢到手（`STOLE A BAT!`）。否则武器掉在前方 6 m 成为可捡道具。

**通缉等级（`HEAT`，0–3 星，HUD 顶栏）**
- 警车在 30 m 内时，玩家每打中一次 +0.15，KO 再 +0.4。
- 把人打进车流或撞墙也加热度。
- 警车挤你或拦你超过 0.5 s 你还不停：+0.7。
- 停车接受罚款：−1。
- 每秒自然下降 0.04。
- 星级越高：
  - 同时出动的警车越多（每星 +1）。
  - 下一辆来得越快（间隔 ÷ (1 + 0.6 × 热度)）。
  - 反应越快，挤得越狠。
  - 2 星起挤你时不再管路肩上有没有车，可能把你挤进车里。

**罚款（`PATROL.fine/fineStar`）**：停车被放行要交 $30 + 每星 $20，弹出 `FINED $X · MOVE ALONG`。结算里单列一行，从奖金里扣。所以要么停车交钱，要么跑，跑就会升星、被挤进车流。

**其他改动**
- 从后方刷出的警车会找一条没有车的车道出来，都不空就等 1 s。原来会刷在车上。
- 结算多两行：打进车流/撞墙、罚款。
- `earned = max(0, 名次奖金 + KO + 报仇 + 打进车流 − 罚款)`。

### 3.3.11 宿敌和激励广告（2026-11-09，SIM_VERSION 13）

**宿敌（`career.ts` 的 feud，存档里 `save.feud`）**
- 每个对手对玩家有一个"仇恨值" beef。每局结算：把玩家打下车一次 +2，比玩家先到终点 +1，被玩家打下车一次 −1，最低 0。
- 没有宿敌时，beef 最高且 ≥ 6 的那个成为宿敌，beef 清零。结算页出现 `☠ NEW NEMESIS` 卡片。
- 宿敌在模拟里（`World.nemesis`）：
  - 极速 +0.6 m/s，攻击性 +0.2，血量 +2（`C.NEMESIS`）。
  - 每局一开始就像记仇一样追着玩家打（`hates(id)`），不会再被记成普通仇人。
- 奖励：每把宿敌打下车一次 $150，比它先到终点 $100，都乘本级奖金倍率。打中时闪 `REVENGE! +$…`。
- 击溃：同一局里**既把宿敌打下车、又比它先到终点**，才算赢它一次。赢满 3 次（`BREAK_AT`）击溃，额外 $500，结算页 `☠ X is BROKEN`。之后由别人的 beef 产生下一个宿敌。
- 为什么不按打下车次数算：实测玩家每局能打下宿敌 2.5–3 次，按次数算 1–2 局就击溃，宿敌不成气候。现在的规则大约 4–5 局击溃，正好跨一个杯赛。
- 比赛开始时倒计时下方显示宿敌卡：名字、它打下过你几次、已赢几次（`beaten n/3`）、每次的赏金。名牌带 ☠。

**平台层（`src/platform.ts`，Playgama Bridge v2）**
- `index.html` 第一个脚本加载 Bridge；`public/playgama-bridge-config.json` 定义广告位：插屏 `race_end`，激励 `double_cash`、`remount`。
- `boot()` 先 `initPlatform()`，再从 Bridge 存储读存档（键 `save`；读不到时迁移旧的 localStorage `dummy-brawl-v1`），全部就绪后 `game_ready`。
- 生命周期：开赛 `level_started`；前 3 名结束 `level_completed`，否则 `level_failed`。
- 平台暂停（`PAUSE_STATE_CHANGED`）停住模拟和声音，和玩家自己的暂停分开；`AUDIO_STATE_CHANGED` 控制静音。
- 激励广告只在收到 `rewarded` 状态时发奖；`closed` / `failed` 不发。120 s 超时保护。
- 本地开发（平台 `mock`）用假广告：遮罩 1.2 s 后算看完。`?noads` 关掉，`?fakeads` 在构建版里打开。

**激励广告两处**
- 结算页 `▶ Double it`：本局所得再加一份，结算表多一行 `Ad bonus ×2`。每局一次。
- 摔车后 `▶ Back on now`：倒地 0.6 s 后出现，每局一次。看完立刻扶回车上（输入 `remount`，回放里记在按键位第 2 位），带正常的起车无敌时间。广告失败不算用掉。
- 插屏：结算后点 `Next race` 时调一次，频率交给 Bridge。

| | 宿敌打下玩家 | 玩家打下宿敌 | 宿敌先到终点 | 前 3 |
|---|---|---|---|---|
| 无宿敌 | — | — | — | 75% |

### 3.3.12 三个赛季、升级上限、六台载具：3 小时的生涯（2026-11-09，SIM_VERSION 14）

目标：一次完整生涯（从 Amateur Rookie Cup 到 Legend Neon Coast 夺冠）给玩家约 3 小时内容，而且后面不能越打越无聊。

**赛季（`C.TIERS`，存档 `save.tier`）**
- 五个分级（Rookie Cup → Neon Coast）打完拿冠军后进入下一个赛季，从 Rookie Cup 重新打，共三个赛季。名字前加赛季名（`Pro Dust Bowl`）。
- 对手的速度按"赛季 × 分级"单独定（`Tier.top[分级]`，加到对手和警车的极速上）。取值依据：玩家在那一站最多能有的速度（本赛季的升级上限 + 那时能买的载具），减去一个往上越来越小的领先量。前面玩家快 5 m/s 左右，最后一站只快 0–1 m/s。

| 赛季 | 对手极速加成（5 个分级） | 智力 | 对手血量 | 车流 | 警车 | 奖金倍率 | 赛道长度 |
|---|---|---|---|---|---|---|---|
| Amateur | 0 / 1.8 / 3.6 / 5 / 6.4 | +0 | +0 | ×1 | +0 | ×1 | ×1 |
| Pro | 7.5 / 8.5 / 10 / 11 / 12.5 | +0.12 | +1 | ×1.15 | +1 | ×2 | ×1.12 |
| Legend | 13.5 / 14.5 / 15.5 / 16.5 / 17.5 | +0.24 | +2 | ×1.3 | +1 | ×3 | ×1.18 |

- 分级自己的奖金倍率 1 / 1.5 / 2.1 / 2.8 / 3.6，和赛季倍率相乘。

**升级上限（`C.UPGRADE_CAP`）**
- 每项最高级：极速 10、操控 8、耐打 6（`UPGRADE_MAX`）。
- 每个赛季只开放一部分：Amateur 6/6/6，Pro 8/7/6，Legend 全开。到上限后按钮显示 `🔒 Pro`，进度条上锁住的格子画成虚线框。
- 价格 `250 × 1.6^级`。
- 为什么要上限：不加的话第一赛季的钱就能把升级买满，后两个赛季对手怎么提速都追不上，实测 bot 全程第一。

**载具（`C.VEHICLES`，存档 `save.garage`）**

| 载具 | 价格 | 解锁（第几站） | 极速 | 操控 | 耐打 | 加速 |
|---|---|---|---|---|---|---|
| Test Scooter | 0 | 0 | 0 | 0 | 0 | 0 |
| Shopping Cart | 3500 | 2（Amateur Maple Run） | +0.8 | −0.6 | +2 | 0 |
| Office Chair | 9000 | 4（Amateur Neon Coast） | +1.8 | +2 | 0 | +1.5 |
| Mobility Scooter | 20000 | 6（Pro Dust Bowl） | +3 | +0.5 | +2 | +0.5 |
| Toilet Rocket | 45000 | 9（Pro Neon Coast） | +4.6 | 0 | +1 | +2.5 |
| Jet Bathtub | 75000 | 12（Legend Maple Run） | +6.2 | +1 | +2 | +3 |

- "第几站" = 赛季 × 5 + 分级。到了这一站才能买；买过的随时换着骑。
- 结算页的车库：正在骑、已拥有（点一下换上）、可买（价格）、未解锁（`🔒 站名`）。

**模型（`src/view/rider.ts` 的 `buildRide`）**
- 全部代码建模加顶点色，和其他东西一样。
- 购物车：人站着推，前面是车筐，脚踩底板。其余四台人是坐着的：大腿水平、小腿往下，骨盆和上身按座高往下挪（`torsoY`），拖尾特效跟着上身高度。
  - 办公椅：五星脚加座椅靠背。
  - 代步车：扶把加小旗。
  - 马桶火箭：马桶圈、水箱、底下一个助推器加两个火焰锥。
  - 喷气浴缸：圆角浴缸、水面、喷口、小黄鸭、爪脚。
- 对手的载具（`scene.ts` 的 `rivalRide`）：第一赛季都骑滑板车；之后按编号在当时已解锁的载具里轮换（乘数 7，和任何载具数互质，所以一场里种类分散）；暴徒一直骑滑板车。只影响画面，不进模拟。

**生涯实测**（`npx tsx scripts/career.ts 1 0.6 race 140`，每局另加 20 s 倒计时、结算和商店）
- 一共 60 局，161 分钟；之前几次调参的不同 bot 是 164–178 分钟（有一两次杯赛要重打）。
- 每局最长 132–175 s，符合 120–180 s 的目标。
- 名次在 Pro 和 Legend 明显更乱；最后一站 bot 只领先 0.1 m/s，拿了 3、1、5、2。
- bot 的躲避和出手接近满分，人类玩家会慢一些，所以实际生涯应在 3 小时以上。
- 购买策略：先买下一台载具，再买最便宜的升级；下一台载具差价在两局收入以内时先存钱。

**测试**
- `src/career.test.ts`：结算奖金；进入下一赛季和最后一个赛季；升级上限和锁；按站解锁、买车和换车；旧存档和坏存档的解析。
- `src/sim/world.test.ts`：载具属性进到玩家身上；后面的赛季对手更快、更耐打、赛道更长。
- 金标准哈希更新到 v14（`OPTS` 加 `tier: 1, vehicle: 2`）。

### 3.4 着色器预热和画质分档

- 开场内容在加载画面下 `compileAsync`；第一帧之后再 `warmRest`；阴影深度变体用离屏绘制预热。**不要**第一帧前把所有程序都编译完（Swarm Orbit 在弱 Windows ANGLE 机器上卡了 7–13 s）。
- 用 `PCFShadowMap`（r186 去掉了 PCFSoft，会导致全部重编译）。透明网格单面 + `forceSinglePass`。
- 画质 6 档沿用 `src/view/quality.ts`：低于 40 fps 持续 3 s 降一档，低于 15 fps 直接降到底；高于 57 fps 30 s 才升，每局最多升一次，升了守不住 54 fps 就退回并锁定。
- 降档顺序：阴影 → 粒子和路边草 → 像素比 2 / 1.5 / 1 / 0.75 / 0.5。竞速游戏再加一条：**先缩视距**，再降像素比。
- 软件 GL（SwiftShader、llvmpipe）直接从最低档开始：像素比 0.5，无 MSAA 无后处理。Swarm Orbit 实测 5.1 → 20.7 fps。
- `?quality=` 参数强制档位，开发服务器锁高档。

### 3.5 HUD

Swarm Orbit 在 Galaxy A16 上的瓶颈不是 WebGL，是 DOM HUD 重绘：

- 每个会变的 HUD 块单独 `will-change: transform`。
- 进度条、速度表用 `transform: scaleX`，不改 `width`；不做 filter 动画。
- 名次、速度、生命这类每帧都变的数字，考虑直接画进 WebGL（字形图集），不走 DOM。

### 3.6 横竖屏

从第一天起两种方向一起设计（Swarm Orbit 记忆 both-orientations）：

- **竖屏 9:16**：镜头更高、更俯视，能看到更远的路和两侧对手；操作区在下方三分之一。
- **横屏 16:9**：镜头低、贴地，更有速度感；按钮贴底边一行，不放右侧（Swarm Orbit 横屏右侧栏挨着 Playgama 的游戏列表，误触）。
- **1:1**：YouTube Playables 要求，按竖屏方案裁。
- 检查尺寸：390×844、844×390、768×1024、1280×720、1920×1080，加 800×450 小嵌入。

### 3.7 平台层和数据

- 存储只走 Bridge，Playgama 上不用 localStorage；YouTube 上走平台存储。
- `showRewarded` 只在状态为 `rewarded` 时返回 true；不支持激励广告时隐藏按钮。
- 插屏：每个自然停顿都调 `showInterstitial`，让 Bridge 自己控制频率，不加自己的计时器。
- 埋点沿用 Swarm Orbit 的事件集：`load`、`boot_left`、`boot_error`、`funnel_*`、`guide_*`、`idle_*`、`quit_*`、`performance_sample`、`session_time`。事件名里带步骤，`kind` 字段用固定词（Playgama 会把自由文本打码）。
- 新增竞速相关漏斗：`funnel_race1_start` / `first_hit` / `first_crash` / `race1_finish` / `race2_start`。第一局里"打到第一个人"之前流失多少，是最该盯的数。
- CI：typecheck → 单文件 ≤500 行 → 覆盖率 → build → 包体大小。

#### 3.7.1 界面多语言（2026-11-10，不动模拟，SIM_VERSION 仍是 14）

- 语言：en、ru、es、pt、tr、de、fr。代码在 `src/i18n/`，每种语言一个文件；`en.ts` 是所有 key 的来源，其他语言的类型是 `Record<Key, string>`，少一个 key tsc 就报错。
- 选语言：
  - 页面加载时先按浏览器语言选一次。
  - `initPlatform()` 之后改用 Bridge 的 `platform.language`。
  - URL 带 `?lang=xx` 时它优先，平台语言不再覆盖，用于测试。
  - 只取前两个字母（`pt-BR` → pt），不认识的语言回落到英文。`<html lang>` 跟着改。
- 用法：`t(key, {变量})`，文本里写 `{name}` 占位；钱写成 `${n}`，显示为 `$300`。名次用 `ord(n)`，每种语言各写一个：

| 语言 | 写法 |
|---|---|
| en | 1st / 2nd / 11th |
| ru | 1-е |
| es | 1.º |
| pt | 1º |
| tr、de | 1. |
| fr | 1re / 2e |

- `Hud` 在平台就绪前就创建了，所以固定文字（拍打提示、操作提示、补救按钮、暂停菜单）放在 `Hud.localize()` 里。`main.ts` 的 `localize()` 先设标题页，再调用它；换语言后再调一次。
- 不翻译的部分：分级、赛季、对手、载具名都是专名，保持英文；"你"翻译（`riderName(0)` 走 `t('you')`）。载具简介翻译。
- 一个文本在不同语法里形式不同时，就拆成几个 key，不在代码里拼词：平底锅和球棒分开（`stolePan`/`stoleBat`），"撞进车流/锥桶/墙"各一条，奖金写在文本里。
- 排版：
  - 横幅和宿敌卡片原来不换行，现在 `width: max-content; max-width: 94vw / 92vw`，长文本自动折行。
  - 在 375×812 竖屏下逐条检查了 7 种语言的全部横幅：最多两行。唯一超出的一条俄语改短了。
  - 俄语、德语的结算页（行、升级按钮、车库卡、下一局按钮）、宿敌卡、HUD 都没有溢出。
- 测试 `src/i18n/i18n.test.ts`：
  - 每种语言的 key 与英文完全一致，且每条的占位符集合相同，不能为空。
  - 语言代码的解析。
  - 占位符的填充和各语言的名次写法。

### 3.8 不要做的事

- 不要自己打开 Playgama 沙盒、QA、游戏页（会增加启动次数、拉低平均时长）。
- 不用 PBR 贴图，不用 AI 生成的模型。描边让三角面翻倍，所以按整场预算控制（见 3.3.1），不按单个模型卡 1500 面。
